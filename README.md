# Code Snake

## Objetivo

Code Snake é uma versão do clássico Snake com identidade visual inspirada em programação. Controle a cobra, colete tokens de código, acumule pontos e cresça sem colidir.

## Como jogar

- Use as setas para cima, baixo, esquerda e direita.
- Também é possível usar W, A, S e D.
- Colete os tokens `</>` para a cobra crescer.
- A partida termina ao bater em uma parede ou no próprio corpo.
- Use **Jogar Novamente** para reiniciar todos os dados da partida.
- Durante o jogo, a tecla Espaço pausa ou retoma a movimentação.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Instalação / execução

Não há instalação obrigatória. Clone ou baixe o repositório e abra o arquivo `index.html` em um navegador moderno.
